# Security

Initiative is a static page: the table is kept in the browser's local storage and never sent to a server. The only network traffic besides the page itself is page-view counting by Vercel Web Analytics on the hosted site.

If you find a vulnerability (for example a save file that runs script when loaded), please report it privately through [GitHub's private vulnerability reporting](https://github.com/WojtekTheWebDev/initiative/security/advisories/new) rather than in a public issue.
